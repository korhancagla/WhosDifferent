# Kim Farkli Frontend

React + Vite frontend for the realtime canvas bluff game.

## Local development

```bash
npm install
VITE_SOCKET_URL=http://localhost:3001 npm run dev
```

## Production build

```bash
VITE_SOCKET_URL=https://kim-farkli-api.onrender.com npm run build
```

Upload the contents of `dist/` to the static host.
